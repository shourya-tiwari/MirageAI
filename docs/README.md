# Documentation index

Start with the root `README.md` for results, installation and usage. The files
here are the project's working documents, kept up to date as the project ran.

| File | What it is | Read it when |
|---|---|---|
| [PROJECT.md](PROJECT.md) | Problem statement, objectives, research questions, scope, data sources, features, method, rubric mapping, known limitations | You need the overall framing |
| [INSTRUCTIONS.md](INSTRUCTIONS.md) | Repo structure, environment, the eight **ML hygiene rules**, code conventions, workflow | Before writing any code |
| [DECISIONS.md](DECISIONS.md) | Every non-obvious choice (D-001 onward): decision → why → alternatives rejected → viva one-liner | Before changing a method, and to prepare for the viva |
| [REFERENCE.md](REFERENCE.md) | Band scaling, QA bits, index formulas, Earth Engine pitfalls, CV and SHAP notes, bibliography | Implementing or checking a data-processing detail |
| [TASKS.md](TASKS.md) | The task list by phase (T0.1 … T9.x), ticked when done and verified | Finding what is next |
| [ROADMAP.md](ROADMAP.md) | Phases, deliverables, exit criteria and status | Tracking progress |
| [CHANGELOG.md](CHANGELOG.md) | What changed in each release, with results per phase | Reconstructing how a number came to be |
| [LEARNING_LOG.md](LEARNING_LOG.md) | Research diary: dated insights, surprises and bugs, each with evidence and impact | Writing the discussion, or understanding a finding |
| [DASHBOARD.md](DASHBOARD.md) | How the Streamlit dashboard is built and what each page shows | Running or extending the dashboard |
| [MIGRATION.md](MIGRATION.md) | Moving the project to a new machine and proving nothing changed | Setting up on another computer |

Two longer guides live at the repository root:

* `../project_deep_dive.md`: a component-by-component technical guide (what, why,
  how, when, where) detailed enough to rebuild the project.
* `../learning_log.md`: a beginner-to-advanced study guide built on this
  repository, with interview and viva questions. (Not to be confused with
  `LEARNING_LOG.md` here, which is the project's research diary.)

Dashboard screenshots used by the root README are in `images/`.

Historical note: entries written before the rename (D-045) still say "Ushna";
they record what was true at the time and are not rewritten.
